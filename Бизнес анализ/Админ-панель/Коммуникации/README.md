# Коммуникации

> Статус: заготовка. Содержимое детализируется в следующей итерации.

## Назначение

Раздел обеспечивает работу службы поддержки и управление уведомлениями и объявлениями платформы. Уведомления, настройки, шаблоны и история доставки принадлежат отдельному Notification Service с собственной PostgreSQL-базой; сервис получает доменные события через Kafka.

## Основные сценарии

- работа с очередью обращений: приём в работу, ответ, смена статуса, назначение исполнителя;
- использование шаблонов ответов;
- контроль времени реакции и просроченных обращений;
- управление шаблонами уведомлений и правилами их отправки;
- просмотр истории отправленных уведомлений;
- публикация массовых объявлений для выбранных групп пользователей.

| Документ | Содержание |
