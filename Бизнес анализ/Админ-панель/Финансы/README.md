# Финансы

> Статус: заготовка. Содержимое детализируется в следующей итерации.

## Назначение

Раздел обеспечивает контроль денежного контура платформы: журнал операций, балансы, продажи пакетов и абонементов, тарифы и комиссии, выплаты преподавателям, финансовая отчётность.

## Основные сценарии

- просмотр журнала операций с фильтрами по пользователю, типу, периоду;
- просмотр балансов учеников и преподавателей, включая зарезервированные средства;
- ручное пополнение баланса и корректировка с обязательным комментарием;
- настройка пакетов уроков и абонементов, просмотр продаж;
- настройка тарифов курсов и комиссии платформы, включая индивидуальную;
- настройка фиксированной цены группового занятия с каждого ученика без деления стоимости между участниками;
- контроль списаний при неявке по действующей политике отмены;
- обработка запросов на выплату: очередь, подтверждение, отклонение, история;
- формирование финансовых отчётов и выгрузок за период;
- разбор расхождений: зависшие резервы, невыполненные списания.
