# Преподаватели

## Назначение

Раздел обеспечивает работу с преподавателем как исполнителем: реестр, проверку анкеты и документов, публикацию в каталоге, закрепление учеников, переходы к назначениям на курсы, индивидуальную комиссию, нагрузку и контроль проблемных занятий. Описан полный целевой объём MVP, включая групповые и регулярные занятия; это требования, а не отчёт о готовой реализации.

## Ключевые решения раздела

| Тема | Решение |
|---|---|
| Границы | Учётная запись — в «Пользователях и доступе», учебные зачисления — в профильных разделах, денежные корректировки и выплаты — в «Финансах» |
| Проверка | Обязательны анкета, документ об образовании и описание опыта; собеседование — по усмотрению сотрудника |
| Публикация | Отдельное действие после верификации и проверки готовности профиля |
| Изменение проверенных данных | Предметы, образование и опыт проходят повторную модерацию; прежняя версия действует до решения |
| Цена и расписание | Меняются без повторной верификации; подтверждённые брони не пересчитываются задним числом |
| Снятие с публикации | Запрещает новые брони и новые регулярные вхождения, сохраняет существующие занятия |
| Отзыв верификации | Отменяет будущие уроки с полным возвратом, сохраняет идущий урок до штатного завершения |
| Назначения | Закрепление ученика не создаёт бронь, резерв и зачисление на курс автоматически |
| Комиссия | Индивидуальную ставку меняет суперадминистратор по отдельному разрешению; менеджер просматривает |
| Качество | Посещаемость, обращения и срывы; оценки, отзывы и рейтинги отложены за пределы MVP |
| Доступ | Общий каталог кодов и предустановленные роли из «Пользователей и доступа»; связанные вкладки требуют собственных прав |
| История | Обязательный перечень общего журнала; версии верификации и результаты проверок доступны как часть процесса |

Числовые настройки платформы и правила финансовых продуктов не вводятся повторно: соответствующие документы остаются источниками этих параметров.
