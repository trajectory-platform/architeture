# Преподаватели

> Статус: заготовка. Содержимое детализируется в следующей итерации.

## Назначение

Раздел обеспечивает работу с реестром преподавателей: верификацию, публикацию в каталоге, назначение учеников и курсов, настройку индивидуальной комиссии, контроль нагрузки и качества.

## Основные сценарии

- просмотр реестра преподавателей со статусом верификации, нагрузкой и рейтингом;
- проверка и верификация заявки преподавателя;
- публикация и снятие с публикации в каталоге;
- просмотр карточки: профиль, предметы, цена, расписание, ученики, начисления, отзывы;
- назначение учеников и курсов преподавателю;
- установка индивидуальной комиссии платформы;
- просмотр истории уроков и срывов;
- блокировка преподавателя.
