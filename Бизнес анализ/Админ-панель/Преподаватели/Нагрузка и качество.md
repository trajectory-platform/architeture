# Нагрузка и качество

## 1. Назначение

Операционная оценка занятости преподавателя и причин несостоявшихся занятий. Раздел помогает распределять учеников и находить случаи, требующие разбора. В МВП качество оценивается по посещаемости, срывам и обращениям; оценки, отзывы и рейтинги отложены.

Доступ: `teacher_profile_view`. Данные расписания требуют `schedule_calendar_view`, уроков — `schedule_lesson_view`, посещаемости — `schedule_attendance_view`, обращений — `comms_ticket_view`.

## 2. Основные сценарии

1. Проверить свободное время перед назначением ученика.
2. Сравнить плановую занятость и фактическое проведение уроков за период.
3. Найти повторяющиеся неявки преподавателя, отмены и технические проблемы.
4. Перейти от показателя к конкретным урокам или обращениям и проверить основание расчёта.
5. После разбора увидеть исправленную статистику без изменения исходных фактов подключения.

## 3. Экран показателей

Экран доступен как вкладка карточки преподавателя. Вверху выбираются период и часовой пояс сотрудника. Пресеты: ближайшие 7 дней для планирования, прошедшие 30 дней для качества, произвольный период. Показатели реестра и карточки совпадают при одинаковых условиях.

### 3.1 Нагрузка

| Показатель | Правило расчёта |
|---|---|
| Доступные часы | Продолжительность объединения окон доступности в периоде за вычетом исключений; занятые части окон также входят в знаменатель |
| Забронированные часы | Сумма плановой длительности подтверждённых неотменённых занятий в периоде; пересечение с границами периода учитывается по фактической части интервала |
| Занятость | Забронированные часы / доступные часы × 100%; при нулевой доступности — «Не рассчитывается» |
| Свободные часы | Оставшееся незанятое время в действующих окнах доступности |
| Будущие уроки | Подтверждённые запланированные уроки с началом в периоде, время начала которых ещё не наступило |
| Проведённые уроки | Уроки с подтверждённым итогом проведения и началом в периоде; для группы достаточно подтверждённого проведения хотя бы по одному ученику, урок учитывается один раз |
| Фактические часы преподавателя | Сумма непересекающихся интервалов присутствия преподавателя в уроках выбранного периода |
| Ближайший свободный слот | Первое доступное для новой брони время с учётом длительности и действующих ограничений |

Групповое занятие занимает время преподавателя один раз: урок с семью учениками не превращается в семь часов нагрузки. Ученические места и число уникальных учеников показываются отдельными показателями.

Историческая нагрузка рассчитывается по сохранённым данным доступности и занятий соответствующего периода. Текущее редактирование шаблона расписания не меняет отчёт за прошлый период. При отсутствии исторических данных показывается «Нет данных», а не расчёт по сегодняшнему шаблону.

### 3.2 Качество и посещаемость

| Показатель | Правило расчёта |
|---|---|
| Неявки преподавателя | Число уроков с подтверждённым итогом «Неявка преподавателя» |
| Отмены преподавателем | Число отменённых уроков по его инициативе; своевременные и поздние показываются раздельно по условиям брони |
| Технические срывы | Число уроков с установленной технической причиной; неподтверждённые случаи показываются в открытых разборах |
| Открытые разборы | Число уникальных уроков с незавершённым разбором, даже если по уроку несколько обращений |
| Обращения | Число обращений, связанных с преподавателем; категория, статус и число подтверждённых проблем показываются отдельно |
| Посещаемость учеников | Число присутствовавших ученических мест / число мест с установленным итогом «Присутствовал» или «Неявка» × 100% |
| Доля неявок преподавателя | Его подтверждённые неявки / (проведённые уроки + его подтверждённые неявки) × 100%; при нулевом знаменателе — «Не рассчитывается» |

Для показателей уроков период определяется по плановому началу занятия. Для обращений — по дате создания обращения; это подписано отдельно. Отменённые места, технические срывы без установленной посещаемости и незавершённые разборы не включаются в знаменатель посещаемости. Неявка одного ученика не означает срыв всей группы.

Факты подключения и административная корректировка посещаемости показываются раздельно. Переподключения не увеличивают число посещённых уроков. Одно занятие не учитывается повторно после повторной обработки завершения.

### 3.3 Детализация и состояния

Каждый счётчик открывает список соответствующих уроков или обращений с теми же фильтрами. Рядом показаны время обновления и применённый период.

| Состояние | Поведение |
|---|---|
| За период нет уроков | Нулевые счётчики, доли без знаменателя — «Не рассчитывается» |
| Идёт обработка результата | Метка «Данные обновляются», последний известный результат с временем расчёта |
| Нет права на источник | Показатель и переход скрыты |
| Ошибка источника | Сообщение у соответствующего блока и «Повторить»; другие блоки остаются доступны |

## 4. Действия сотрудника

| Действие | Результат | Разрешение |
|---|---|---|
| Открыть свободное время | Календарь преподавателя | `schedule_calendar_view` |
| Открыть проблемные уроки | Отфильтрованный список занятий | `schedule_lesson_view` |
| Начать или продолжить разбор | Карточка проблемного занятия | `schedule_lesson_edit` |
| Открыть обращения | Список обращений преподавателя | `comms_ticket_view` |
| Снять с публикации | Отдельное подтверждение с причиной | `teacher_publication_edit` |

Показатель сам по себе не запускает санкцию. Сотрудник изучает конкретные случаи и принимает отдельное решение по правилам верификации, публикации или блокировки. Просмотр записи требует отдельного права и основания; присутствие сотрудника в комнате в МВП не предусмотрено.

## 5. Правила и ограничения

1. Нет единого балла качества, рейтинга, автоматической блокировки по проценту или сравнения преподавателей без раскрытия исходных чисел.
2. Жалоба не считается установленным нарушением до завершения разбора.
3. Число проведённых уроков не означает освоение учебных тем: прогресс принадлежит разделу «Обучение».
4. Служебные показатели и комментарии не публикуются в каталоге преподавателей.
5. Денежные суммы показываются в финансовой вкладке по соответствующим правам и не подменяют статистику проведения.

## 7. Требования

| № | Требование | Трассировка |
|---|---|---|
| TQ-1 | Должны отображаться плановая нагрузка, свободное время и фактическое присутствие преподавателя за период | МВП 18.2, 18.10 |
| TQ-2 | Групповой урок должен учитываться в нагрузке один раз, посещаемость — по каждому ученику | МВП 5.7, 7.21 |
| TQ-3 | Должны быть показаны неявки, отмены, технические срывы, открытые разборы и обращения без рейтингов и отзывов | МВП 18.2, 18.5 |
| TQ-4 | Каждый показатель должен иметь раскрытую формулу, период и переход к исходным объектам | МВП 18.10 |
| TQ-5 | Отсутствие данных и нулевой знаменатель должны отличаться от нулевого результата | МВП 18.10 |
| TQ-6 | Исправления результатов должны обновлять показатели без двойного учёта и удаления исходной посещаемости | МВП 7.21, 12.5 |

## 8. Критерии приёмки

1. Групповой урок длительностью 60 минут с семью учениками даёт один урок и один час плановой нагрузки.
2. При 10 доступных и 6 забронированных часах занятость составляет 60%; при отсутствии доступности процент не вычисляется.
3. Три переподключения ученика остаются одним посещённым местом; пересекающиеся интервалы не суммируются повторно.
4. Два обращения об одном уроке дают два обращения и один открытый разбор.
5. Переход из числа неявок открывает ровно уроки, вошедшие в показатель.
6. Подтверждённая техническая проблема не увеличивает счётчик неявок преподавателя.
7. Изменение будущих окон доступности не меняет исторический отчёт; повторное завершение урока не увеличивает число проведённых занятий.
