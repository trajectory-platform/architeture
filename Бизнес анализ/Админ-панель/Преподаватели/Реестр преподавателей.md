# Реестр преподавателей

## 1. Назначение

Рабочий список преподавателей как исполнителей: найти заявку, проверить допуск к работе, предметы, доступность и нагрузку, перейти к назначениям и разбору проблем.

Доступ к разделу: `teacher_profile_view`.

## 2. Разграничение со списком пользователей

| Раздел | Задача | Содержание |
|---|---|---|
| [Пользователи и доступ](../Пользователи%20и%20доступ/README.md) | Управлять учётной записью | Роли, вход, сессии, блокировка и удаление |
| Реестр преподавателей | Управлять работой преподавателя | Верификация, публикация, предметы, доступность, назначения, нагрузка |
| [Финансы](../Финансы/README.md) | Управлять денежными обязательствами | Тарифы, комиссии, начисления, корректировки и выплаты |

Реестр содержит преподавателей с момента первой подачи заявки, включая отклонённые заявки и преподавателей, выданных сотрудником через карточку пользователя. Неотправленный черновик самозаявки в очередь сотрудника не попадает. Исторические записи преподавателей после отзыва роли или анонимизации доступны по явному фильтру.

## 3. Основные сценарии

1. Найти преподавателя по имени, контактам или идентификатору.
2. Открыть очередь заявок и изменений, требующих проверки.
3. Найти верифицированных преподавателей по предмету и наличию свободного времени.
4. Проверить неопубликованные профили и причины ограничения работы.
5. Выявить преподавателей с проблемными занятиями и открыть соответствующий список уроков.
6. Выгрузить отфильтрованный реестр для операционного отчёта.

## 4. Экран списка

|---|---|---|---|
| Преподаватель | Имя, аватар, ссылка на карточку | да | да |

| Публикация | Опубликован или не опубликован | да | да |
| Предметы | Действующий одобренный состав; для новой заявки — заявленный с соответствующей подписью | — | да |
| Цена и длительность | Условия индивидуального занятия по умолчанию; групповой тариф смотрят в курсе | по цене | да |
| Будущие уроки | Число подтверждённых уроков на выбранный период | да | да |

| Заявка подана | Дата отправки текущей заявки | да | скрыта |

Комиссия доступна только при `teacher_commission_view`. Показатели расписания требуют `schedule_calendar_view`, проблемных занятий — `schedule_lesson_view`. Без соответствующего разрешения колонка отсутствует, в том числе в выгрузке; скрытая пользователем колонка и запрещённая по правам колонка различаются.

Даты показываются в часовом поясе сотрудника с подписью. Период показателей по умолчанию — ближайшие 7 календарных дней; доступны 30 дней и произвольный период. Формулы заданы в [Нагрузке и качестве](Нагрузка%20и%20качество.md). Рейтинги и отзывы в МВП не отображаются.

### 4.2 Поиск и фильтры

Поиск запускается после ввода минимум 3 символов с задержкой после окончания ввода. Имя и email ищутся по подстроке без учёта регистра, телефон — по нормализованным цифрам. Полный идентификатор открывает соответствующую карточку, если она доступна сотруднику.

| Фильтр | Тип | Значения |
|---|---|---|
| Верификация | множественный выбор | Не подана, на модерации, верифицирован, отклонена |
| Требует проверки | да / нет | Первичная, повторная заявка или изменения на проверке |
| Публикация | множественный выбор | Опубликован, не опубликован |
| Предмет и направление | множественный выбор | Справочники платформы |
| Статус аккаунта | множественный выбор | Статусы учётной записи |
| Роль преподавателя действует | да / нет | Для поиска исторических профилей |
| Цена | диапазон | Условия индивидуального занятия |
| Часовой пояс | множественный выбор | Пояс преподавателя |
| Свободные слоты | да / нет | В выбранном периоде |
| Проблемные занятия | да / нет | Есть открытые разборы в выбранном периоде |
| Дата подачи заявки | период | Сегодня, 7 дней, 30 дней, произвольный |

Фильтры объединяются по «И», значения одного фильтра — по «ИЛИ». Активные фильтры показаны снимаемыми метками; есть общий сброс. Поиск, фильтры, период и сортировка сохраняются в адресе страницы. По умолчанию исключены удалённые аккаунты и профили с отозванной ролью.

### 4.3 Действия

| Действие | Где | Разрешение | Подтверждение |
|---|---|---|---|
| Открыть карточку | строка | `teacher_profile_view` | — |
| Открыть проверку | меню строки | `teacher_verification_view` | — |
| Опубликовать / снять с публикации | меню строки | `teacher_publication_edit` | да, причина и последствия |
| Открыть расписание | меню строки | `schedule_calendar_view` | — |
| Открыть уроки | меню строки | `schedule_lesson_view` | — |
| Открыть учётную запись | меню строки | `auth_user_view` | — |
| Выгрузить реестр | над таблицей | `teacher_profile_export` | да |

Верификация, комиссия, назначения и блокировка выполняются в соответствующих карточках. Массовая публикация, модерация и блокировка в реестре не предусмотрены.

### 4.4 Навигация и выгрузка

Размер страницы: 25, 50, 100 строк; по умолчанию 50. Показано общее число найденных записей. По умолчанию реестр отсортирован по имени; очередь проверки — по дате подачи от ранних к поздним. Состав колонок сохраняется для сотрудника.

Выгрузка содержит весь отфильтрованный срез, а не только текущую страницу: выбранные сотрудником колонки, доступные ему по правам, период и часовой пояс. Максимум 10 000 строк; при превышении предлагается сузить фильтры. Факт выгрузки, фильтры, состав колонок и число строк фиксируются в журнале.

### 4.5 Состояния

| Ситуация | Отображение |
|---|---|
| Нет результатов | «Ничего не найдено», сброс фильтров |
| Поиск короче 3 символов | «Введите не менее 3 символов» |
| Нет доступных слотов | «Нет слотов»; это не означает блокировку или отсутствие верификации |
| Показатель ещё не получен | «Нет данных»; отсутствие данных не заменяется нулём |
| Ошибка загрузки | Сообщение и действие «Повторить» |
| Удалённый аккаунт | «Удалённый пользователь», без прежних контактов |

## 5. Правила и ограничения

1. Верификация, публикация и статус аккаунта показываются раздельно: одно состояние не заменяет другое.
2. Список не позволяет обойти ограничения бронирования для неопубликованного или неверифицированного преподавателя.
3. Данные изменившейся, но не одобренной анкеты явно отделяются от действующих данных.
4. Блокировка и отзыв роли используют правила карточки пользователя и соответствующие разрешения.
5. Выгрузка и переходы в связанные разделы повторно проверяют права на сервере.

## 7. Требования

| № | Требование | Трассировка |
|---|---|---|
| TR-1 | Должен быть реализован реестр преподавателей с поиском, фильтрами, сортировкой и постраничной навигацией | МВП 18.2, 18.12 |
| TR-2 | Реестр должен разделять состояние аккаунта, верификации, проверки изменений и публикации | МВП 4.5, 4.6, 18.2 |
| TR-3 | Должны отображаться предметы, условия занятий, доступность, нагрузка и открытые проблемы | МВП 18.2, 18.5 |
| TR-4 | Права должны ограничивать колонки, действия, переходы и состав выгрузки | МВП 3.13 |
| TR-5 | Поиск, фильтры, период и сортировка должны сохраняться в адресе; состав колонок — для сотрудника | МВП 18.12 |
| TR-6 | Должна быть реализована журналируемая выгрузка до 10 000 строк | МВП 18.10, 18.13 |
| TR-7 | Исторические профили должны быть доступны по явному фильтру с соблюдением анонимизации | МВП 4.9 |

## 8. Критерии приёмки

1. Фильтр «Верифицирован» и «Не опубликован» находит одобренный профиль, который ещё не публиковали.
2. «Требует проверки» включает опубликованного преподавателя с изменениями образования на проверке.
3. При одинаковых фильтрах, периоде и правах ссылка коллеги открывает тот же срез.
4. Сотрудник без права просмотра комиссии не получает эту колонку ни в таблице, ни в выгрузке.
5. Менеджер видит действия публикации и не видит выгрузку, изменение комиссии и блокировку.
6. При выгрузке более 10 000 записей файл не формируется; предлагается сузить фильтры.
7. Удалённый преподаватель находится по идентификатору и явному фильтру, но не по прежнему email.
