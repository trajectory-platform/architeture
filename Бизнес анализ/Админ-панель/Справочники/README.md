# Справочники

> Статус: заготовка. Содержимое детализируется в следующей итерации.

## Назначение

Раздел обеспечивает ведение справочных значений, используемых во всех модулях платформы. Справочники редактируются администратором и не зашиты в код.

## Состав справочников

| Справочник | Использование |
|---|---|
| Предметы | Профиль преподавателя, курс, каталог, фильтры |
| Направления | Уточнение предмета: подготовка к экзамену, уровень языка, технология |
| Уровни подготовки | Профиль ученика, курс, каталог |
| Типы занятий | Урок, тест, пробное занятие, консультация |
| Длительности занятий | Настройка расписания и цены |
| Причины отмены | Отмена брони, аналитика срывов |
| Категории обращений | Поддержка |
| Статусы и их отображение | Единая палитра статусов в интерфейсах |
| Часовые пояса | Профили пользователей, отображение расписания |

## Основные сценарии

- создание, редактирование и архивирование значения справочника;
- изменение порядка отображения;
- просмотр использования значения в системе перед архивированием;
- запрет удаления значения, на которое есть ссылки.
