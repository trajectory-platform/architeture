# Аналитика и отчёты

> Статус: заготовка. Содержимое детализируется в следующей итерации.

## Назначение

Раздел предоставляет сотрудникам платформы сводную картину работы: активность пользователей, проведённые занятия, срывы, финансовые показатели и качество поддержки.

## Состав

| Отчёт | Показатели |
|---|---|
| Дашборд платформы | Активные ученики и преподаватели, проведённые уроки, срывы, выручка, средний чек |
| Отчёт по преподавателям | Нагрузка, посещаемость, срывы, обращения, начисления; рейтинги и отзывы — после MVP |
| Отчёт по ученикам | Активность, прогресс, оплаты, окончание доступа, отток |
| Финансовый отчёт | Поступления, списания, комиссия, выплаты, зарезервированные средства |
| Отчёт по обучению | Выданные и проверенные задания, результаты тестов, освоение программ |
| Отчёт по поддержке | Количество обращений, время реакции, темы, доля решённых |

## Основные сценарии

- просмотр дашборда за выбранный период;
- построение отчёта с фильтрами по преподавателю, курсу, предмету, статусу;
- сравнение периодов;
- выгрузка отчёта в табличный формат.
