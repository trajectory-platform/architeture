# Контент и материалы

> Статус: заготовка. Содержимое детализируется в следующей итерации.

## Назначение

Раздел обеспечивает управление учебными материалами платформы и статическим контентом интерфейса.

## Основные сценарии

- ведение общей библиотеки материалов: загрузка, категоризация, доступность;
- просмотр материалов, привязанных к курсам, темам и урокам;
- управление записями занятий: просмотр, хранение 1 месяц, досрочное и автоматическое удаление;
- редактирование статических страниц: оферта, политика конфиденциальности, правила уроков, регламент выплат, справка;
- управление баннерами и информационными блоками в интерфейсах;
- ведение шаблонов документов.

## Планируемые документы

| Документ | Содержание |
|---|---|
| `Библиотека материалов.md` | Типы материалов, категории, доступ, поиск |
| `Записи занятий.md` | Хранение 1 месяц, доступ, досрочное и автоматическое удаление, согласия |
| `Статические страницы.md` | Список страниц, редактор, версии, публикация |
| `Баннеры и объявления.md` | Места размещения, период показа, аудитория |
| `Шаблоны документов.md` | Договоры, справки, акты: структура и переменные |
