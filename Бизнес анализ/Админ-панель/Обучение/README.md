# Обучение

## Назначение

Раздел обеспечивает управление учебной структурой платформы: курсы и программы, группы, домашние задания, тесты и банк вопросов, а также контроль качества обучения.

## Основные сценарии

- создание и редактирование курса: предмет, направление, преподаватель, программа, тариф;
- формирование программы курса из тем с указанием порядка;
- публикация и снятие курса с публикации;
- создание групп и управление составом (до 7 учеников);
- ведение шаблонов домашних заданий;
- сборка тестов и наполнение банка вопросов;
- настройка аттестаций по предмету;
- контроль качества: посещаемость, разбор проблемных занятий и жалоб, просмотр записей по отдельному разрешению с причиной; оценки, отзывы и рейтинги отложены за пределы MVP.
