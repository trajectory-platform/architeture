# Настройки платформы

> Статус: заготовка. Содержимое детализируется в следующей итерации.

## Назначение

Раздел содержит глобальные параметры работы платформы. Изменение параметров влияет на поведение бронирования, комнаты урока, денежного контура и хранения данных.

## Состав настроек

| Группа | Параметры |
|---|---|
| Бронирование | Горизонт планирования, минимальный срок до брони, максимальное число активных броней, окно входа в комнату |
| Отмена и перенос | Пороги времени и доли возврата, кто может отменять, лимит переносов |
| Комната урока | Максимальное число участников, максимальная длительность, допуск автозавершения, доступность записи |
| Запись занятий | Обязательность согласия, срок хранения, правила удаления |
| Файлы | Допустимые типы, ограничения размера, сроки хранения по типам |
| Деньги | Валюта, глобальная комиссия, порог выплаты, расписание автовывода |
| Уведомления | Включённые типы событий, время напоминаний до занятия |
| Безопасность | Срок жизни токенов, политика паролей, ограничения частоты запросов |
| Интеграции | Параметры медиасервера, хранилища, OAuth-провайдеров, платёжного шлюза |

## Основные сценарии

- изменение параметра с указанием причины;
- просмотр истории изменений настроек;
- проверка влияния изменения на существующие брони и уроки.

## Правила

1. Изменение настроек доступно только сотруднику с разрешением суперадминистратора.
2. Каждое изменение фиксируется в журнале действий с прежним и новым значением.
3. Изменение параметров бронирования и возврата не применяется задним числом к уже подтверждённым броням.
4. Ключи и секреты интеграций отображаются в маскированном виде и не выгружаются.
