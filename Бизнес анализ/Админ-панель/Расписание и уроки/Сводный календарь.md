# Сводный календарь

## 1. Назначение

Общая картина доступности преподавателей, подтверждённых занятий и конфликтов расписания. Календарь помогает подобрать время и открыть нужный урок; денежные решения и изменение броней выполняются в отдельных сценариях.

Доступ: `schedule_calendar_view`. Управление доступностью: дополнительно `schedule_calendar_edit`.

## 2. Основные сценарии

1. Посмотреть занятия платформы за день, неделю или месяц.
2. Найти свободное время преподавателя под нужную длительность.
3. Изменить разовое окно, повторяющееся правило или исключение доступности.
4. Проверить влияние отпуска и изменения графика на будущие уроки.
5. Открыть бронь, урок или список проблемных занятий из календаря.

## 3. Представления и фильтры

| Представление | Содержание |
|---|---|
| День | Временная сетка, отдельные дорожки выбранных преподавателей |
| Неделя | Занятия по дням с возможностью раскрыть преподавателя |
| Месяц | Количество и краткие подписи занятий; переполнение раскрывается списком дня |
| Список периода | Последовательность событий по времени для плотного расписания |

По умолчанию открывается текущая неделя в часовом поясе сотрудника. Есть переход к дате, «Сегодня», предыдущему и следующему периоду. Список преподавателей поддерживает поиск и постраничную загрузку; в сетке отображаются выбранные преподаватели. Скрытые за переполнением события обозначаются счётчиком.

| Фильтр | Значения |
|---|---|
| Преподаватель | Один или несколько преподавателей, поиск по имени и идентификатору |
| Ученик | Конкретный ученик; поиск по имени и идентификатору |
| Предмет и направление | Значения справочников |
| Курс и группа | Доступные по правам сущности |
| Формат | Индивидуальный, групповой, пробный |
| Состояние | Статус урока; отдельно признаки «Перенос на согласовании» и «Требует разбора» |
| Вид события | Уроки, свободные окна, исключения доступности |

Фильтры комбинируются по «И», значения одного фильтра — по «ИЛИ». Период, представление, часовой пояс и фильтры сохраняются в адресе. При переходе из карточки преподавателя его фильтр уже выбран.

## 4. Событие календаря

| Элемент | Содержание |
|---|---|
| Время | Начало, окончание, длительность, подпись часового пояса |
| Участники | Преподаватель; ученик либо группа и число подтверждённых мест |
| Учебный контекст | Предмет, курс и тема при наличии |
| Состояние | Текстовая метка, значок и цвет |
| Дополнительные признаки | Пробное, регулярное, запрос переноса, проблема |
| Быстрое раскрытие | Идентификаторы брони и урока, текущий итог, разрешённые переходы |

| Событие | Обозначение |
|---|---|
| Свободное окно | Светлый контур, подпись «Свободно» |
| Исключение | Штриховка, подпись «Недоступно» и вид исключения |
| Запланирован | Синяя метка и текст |
| Идёт | Фиолетовая метка, индикатор текущего занятия |
| Завершён | Зелёная метка |
| Отменён | Серая метка, перечёркнутое время |
| Неявка | Красная метка с указанием отсутствовавшей стороны |
| Требует разбора | Дополнительный предупреждающий значок; статус урока сохраняется отдельно |

Цвет не является единственным способом передачи состояния. Групповой урок занимает одно событие преподавателя; неявка одного ученика отображается в деталях и не превращает всё событие в неявку.

## 5. Управление доступностью

### 5.1 Формы

| Объект | Поля |
|---|---|
| Разовое окно | Преподаватель, дата, время начала и окончания, часовой пояс |
| Повторяющееся правило | Преподаватель, дни недели, время начала и окончания, дата начала, необязательная дата окончания, часовой пояс правила |
| Исключение | Преподаватель, интервал или полный день, вид: отпуск, выходной, блокировка времени; причина |

Каждое изменение сотрудником требует причины до 200 символов. Дата окончания не раньше начала, интервал имеет положительную длительность. Для регулярного правила фиксируется часовой пояс преподавателя на момент создания; изменение пояса профиля не меняет ранее созданное правило молча.

### 5.2 Правила изменения

1. Свободные слоты формируются на скользящий горизонт из настроек платформы. Окно доступности и готовый слот — разные объекты: допустимая длительность и ограничения бронирования определяют, какое время можно занять.
2. Пересекающиеся окна доступности объединяются при показе свободного времени; они не создают возможность двойной брони.
3. Исключение исключает свободное время. Если оно пересекает подтверждённые занятия, сохранение блокируется и показывается список конфликтов; сотрудник сначала переносит или отменяет их отдельными действиями.
4. Сужение или удаление окна и изменение регулярного правила также не могут скрытно отменить подтверждённую бронь. До сохранения показываются затронутые занятия и причины конфликта.
5. Редактирование доступности действует на будущее; история проведённых занятий и исторические условия доступности сохраняются.
6. Пауза публикации и отзыв верификации не удаляют график. Они запрещают создание новых броней независимо от наличия свободных окон.
7. Изменение доступности уведомляет преподавателя. Ученики уведомляются о конкретном изменении их занятия только после выполнения переноса или отмены.

### 5.3 Часовые пояса

Время события показывается в выбранном поясе сотрудника; в форме дополнительно видны местное время и пояс преподавателя. Для переноса и брони отображается время каждого участника либо выбранного ученика группы.

Повторяющееся правило сохраняет местное время в своём поясе. При сезонном переводе времени система не выбирает неоднозначный момент молча: отсутствующее или дважды встречающееся местное время требует явного разрешения, а затронутое вхождение показывается как конфликт. Подтверждённое занятие сохраняет свой конкретный момент времени при смене пояса отображения.

## 6. Действия, обновление и ошибки

| Действие | Разрешение | Результат |
|---|---|---|
| Открыть занятие | `schedule_lesson_view` | Карточка урока |
| Открыть бронь | `schedule_booking_view` | Детали бронирования |
| Создать / изменить доступность | `schedule_calendar_edit` | Форма доступности с проверкой конфликтов |
| Создать бронь | `schedule_booking_act_as` и права просмотра | Сценарий управления бронями |
| Перенести занятие | `schedule_booking_act_as` и права просмотра | Форма переноса и его последствия |
| Отменить занятие | `schedule_lesson_cancel` и права просмотра | Предварительный расчёт возврата и подтверждение |

Перетаскивание, если используется, только открывает форму переноса с новым временем и не сохраняет действие само по себе. Календарь не выдаёт доступ в комнату урока.

После изменения календарь обновляет затронутые события. Перед сохранением сервер повторно проверяет свободное время и актуальное состояние. Если слот уже занят или урок начался, операция не выполняется; показана причина и возможность обновить данные.

При отсутствии событий показывается пустое состояние с текущими фильтрами. Ошибка загрузки не отображается как свободное расписание: показаны сообщение, время последнего успешного обновления, если оно было, и кнопка повтора. Создание брони по неподтверждённым данным недоступно.

## 7. Права доступа

| Действие | Суперадминистратор | Менеджер |
|---|---|---|
| Смотреть календарь и доступность | + | + |
| Редактировать доступность с причиной | + | + |
| Создавать, переносить и отменять брони | + | + |
| Менять глобальные параметры расписания и возвратов | + | — |

Права задаются [общим каталогом](../Пользователи%20и%20доступ/Роли%20и%20разрешения.md). Разрешение редактировать календарь не заменяет разрешение на действия над бронями.

## 8. Требования

| № | Требование | Трассировка |
|---|---|---|
| SC-1 | Должен быть реализован сводный календарь на день, неделю, месяц и список периода с фильтрами | МВП 6.18, 18.5 |
| SC-2 | Должны отображаться свободное время, исключения, статусы уроков и отдельные признаки проблем | МВП 6.1–6.5, 7.1 |
| SC-3 | Сотрудник должен управлять разовыми окнами, регулярной доступностью и исключениями с причиной | МВП 6.1–6.4, 18.13 |
| SC-4 | Изменение доступности не должно скрытно изменять подтверждённые занятия | МВП 6.10, 6.14–6.17 |
| SC-5 | Время должно явно отображаться в выбранном поясе с сохранением пояса регулярного правила | МВП 2.20 |
| SC-6 | Групповой урок должен отображаться одним событием, состав мест — в деталях | МВП 5.7, 18.5 |
| SC-7 | Все изменения должны повторно проверять конфликты и права; ошибка загрузки не должна означать свободное время | МВП 6.10, 3.13 |

## 9. Критерии приёмки

1. Одна групповая бронь с семью учениками показана одним событием, в деталях — семь мест.
2. Попытка добавить отпуск поверх подтверждённого урока показывает конфликт и не отменяет урок.
3. Удаление свободного окна не изменяет занятия прошедшего периода.
4. Смена часового пояса отображения меняет подписи времени, но не момент проведения.
5. Создание брони по слоту, занятому другим сотрудником, отклоняется без второй брони.
6. После ошибки загрузки календарь не предлагает считать незагруженное время свободным.
7. Сотрудник с `schedule_calendar_edit` без разрешения действовать над бронями не может перенести урок.
