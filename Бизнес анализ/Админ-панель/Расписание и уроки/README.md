# Расписание и уроки

> Статус: заготовка. Содержимое детализируется в следующей итерации.

## Назначение

Раздел даёт сотрудникам платформы сводную картину расписания и позволяет вмешиваться в брони и уроки: подтверждать, переносить, отменять, разбирать проблемные занятия.

## Основные сценарии

- просмотр сводного календаря платформы с фильтрами по преподавателю, предмету, статусу;
- просмотр списка уроков с фильтрами по дате, статусу, участникам;
- просмотр карточки урока: участники, посещаемость, длительность, запись, заметки, связанные денежные операции;
- создание, перенос и отмена брони от лица участников;
- разбор проблемных занятий: срывы, неявки, технические сбои; при неявке ученика стоимость списывается, если срок бесплатной отмены по действующей политике истёк;
- просмотр и удаление записи занятия;
- ручное завершение зависшего урока.

## Планируемые документы

| Документ | Содержание |
|---|---|
| `Сводный календарь.md` | Представления, фильтры, цветовые обозначения статусов |
| `Список уроков.md` | Поля, фильтры, выгрузка |
| `Карточка урока.md` | Вкладки, поля, действия, связь с деньгами и прогрессом |
| `Управление бронями.md` | Действия администратора, влияние на резервы и возвраты, журналирование |
| `Разбор проблемных занятий.md` | Классификация причин, правила списания при неявке, компенсации, отчётность |
