# Расписание и уроки

## Назначение

Раздел даёт сотрудникам платформы сводную картину доступности и занятий, позволяет создавать, переносить и отменять брони от лица участников, проверять посещаемость, просматривать записи и разбирать проблемные исходы. Описан полный целевой объём MVP: индивидуальные, групповые, пробные и регулярные занятия. Наличие требования не означает готовность реализации.

## Ключевые решения раздела

| Тема | Решение |
|---|---|
| Состояния | Бронь, статус урока, посещаемость места, разбор и денежное исполнение показываются раздельно |
| Группы | Один урок и одно время преподавателя, до семи учеников, отдельная цена и резерв каждого места |
| Регулярность | Каждое вхождение проходит обычное бронирование; ошибка одного не отменяет остальные |
| Индивидуальный перенос сотрудником | Без подтверждения участников, с обязательной причиной и уведомлением обеих сторон |
| Перенос группы | Согласие преподавателя и всех записанных учеников; до применения действует прежнее время |
| Пробное | Одно использованное на пару ученик–преподаватель; возможно бесплатно; право сохраняется при несостоявшемся занятии по правилам документа |
| Неявка ученика | Списание после бесплатного окна, иначе полный возврат по зафиксированным условиям |
| Неявка преподавателя | Полный возврат затронутым ученикам |
| Технический срыв | Ручной разбор без автоматического списания до решения |
| Проведение | При автоматическом завершении — настраиваемый порог совместного присутствия по каждому ученику; спорные случаи направляются на разбор |
| Полномочия менеджера | Обычный расчёт разрешённого итога и завершение зависшего урока; компенсации и корректировки проведённых денег — у суперадминистратора |
| Наблюдение | Подключение сотрудника в комнату отложено; доступны карточка, посещаемость и отдельный просмотр записи |
| Запись | Просмотр сотрудником требует отдельного разрешения, причины и журналирования; отсутствие или отзыв согласия останавливает запись |
| Хранение | Календарный месяц от готовности файла; досрочное удаление общей записи — по решению суперадминистратора, с уведомлением участников |
| Настройки | Числовые пороги и сроки настраиваются в «Настройках платформы»; стартовые значения здесь не назначаются |
| История | Журналируются действия с последствиями для участников, денег и доступа; факты присутствия и денежные операции не переписываются |
