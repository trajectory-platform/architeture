# Список уроков

## 1. Назначение

Табличный поиск запланированных и прошедших уроков платформы: проверить участников и состояние, найти отмены, неявки и технические проблемы, открыть карточку и выгрузить операционный срез.

Доступ: `schedule_lesson_view`.

## 2. Разграничение с календарём и бронями

| Представление | Задача | Единица строки |
|---|---|---|
| [Сводный календарь](Сводный%20календарь.md) | Найти время и оценить график | Событие времени |
| Список уроков | Найти занятие и установить его итог | Один урок, включая групповой |
| [Управление бронями](Управление%20бронями.md) | Проверить резервирование и согласование | Бронь, ученическое место или регулярное правило |

Неуспешная попытка бронирования без созданного урока не образует строку списка уроков: она доступна в бронях. Групповой урок показывается один раз; исходы отдельных учеников раскрываются в карточке.

## 3. Основные сценарии

1. Найти урок по идентификатору или участнику.
2. Посмотреть занятия преподавателя, ученика, курса или группы за период.
3. Выделить уроки с неявками, отменами, незавершёнными разборами или финансовой обработкой.
4. Открыть карточку и перейти к допустимому действию по текущему состоянию.
5. Выгрузить выборку для отчёта с сохранением фильтров и периода.

## 4. Экран списка

### 4.1 Колонки

| Колонка | Содержание | Сортировка | По умолчанию |
|---|---|---|---|
| Урок | Короткий идентификатор, копирование, переход в карточку | — | да |
| Дата и время | Плановое начало, окончание и пояс | да | да |
| Преподаватель | Имя и переход в профиль по правам | да | да |
| Ученики | Имя для индивидуального; группа и число мест для группового | — | да |
| Предмет и курс | Учебный контекст | по предмету | да |
| Формат | Индивидуальное, групповое; метки пробного и регулярного | — | да |
| Статус урока | Запланирован, идёт, завершён, отменён, неявка | да | да |
| Посещаемость | Число присутствовавших и неявок, неизвестный итог отдельно | — | да |
| Длительность | Плановая; фактическая длительность урока отдельно | по плановой | да |
| Проблема | Категория и состояние разбора | да | да |
| Финансовый результат | Обрабатывается, исполнен, требует проверки; сумма списаний и возвратов | — | скрыта |
| Запись | Нет, ожидает согласий, записывается, обрабатывается, готова, ошибка, удаляется, удалена | — | скрыта |
| Перенос | Предложение и состояние согласования, если есть | — | скрыта |
| Бронь и правило | Идентификаторы связанных объектов | — | скрыта |

Посещаемость требует `schedule_attendance_view`, финансовые сведения — `finance_operation_view`, запись — `schedule_recording_view`, сведения о брони и переносе — `schedule_booking_view`. Колонки без прав не выдаются. Переход в профиль не появляется без права просмотра профиля, но имя участника остаётся частью разрешённой карточки урока.

Все даты показываются в поясе сотрудника с подписью. Состав колонок сохраняется для сотрудника. По умолчанию выбран период от начала текущего дня до конца следующих 6 дней, сортировка — от раннего начала к позднему; для исторического периода направление можно изменить.

### 4.2 Поиск и фильтры

Поиск по полному идентификатору урока открывает карточку. По имени, email или телефону участника поиск выполняется по подстроке от 3 символов, без учёта регистра и с нормализацией цифр телефона. Персональные данные удалённых аккаунтов не восстанавливаются поиском.

| Фильтр | Тип / значения |
|---|---|
| Плановое начало | Период; сегодня, ближайшие 7 дней, прошедшие 30 дней, произвольный |
| Преподаватель / ученик | Поиск и выбор одного или нескольких участников |
| Предмет / направление | Справочники |
| Курс / группа | Связанные учебные сущности по правам |
| Формат | Индивидуальный, групповой, пробный |
| Статус урока | Множественный выбор пяти статусов |
| Регулярное занятие | Да / нет, конкретное правило |
| Перенос на согласовании | Да / нет |
| Проблема | Есть / нет, категория, состояние разбора |
| Неявка | Преподаватель, один или несколько учеников, все ученики |
| Финансовый результат | Обрабатывается, исполнен, требует проверки — по правам |
| Запись | Состояние записи — по правам |

Фильтры между собой объединяются по «И», значения одного фильтра — по «ИЛИ». Выбранный период относится к плановому началу, а не дате фактического завершения или создания брони. Для перенесённого урока используется текущее плановое время; прежнее видно в карточке и истории.

Поиск, фильтры, сортировка, период и часовой пояс сохраняются в адресе страницы; активные фильтры можно снять по одному или сбросить. Размер страницы — 25, 50, 100, по умолчанию 50; показано общее число уроков.

### 4.3 Действия

| Действие | Разрешение | Подтверждение |
|---|---|---|
| Открыть карточку | `schedule_lesson_view` | — |
| Открыть бронь | `schedule_booking_view` | — |
| Перенести | `schedule_booking_act_as` и права просмотра | Форма переноса, причина |
| Отменить | `schedule_lesson_cancel` и права просмотра | Последствия по каждому месту, причина |
| Открыть / продолжить разбор | `schedule_lesson_edit` | Изменения с основанием |
| Выгрузить | `schedule_lesson_export` | Да |

Ручное завершение, изменение итога и просмотр записи выполняются из карточки после изучения деталей. Массовая отмена произвольной выборки и массовая смена статуса не предусмотрены. Отмена регулярного правила — отдельный сценарий с предварительным расчётом каждого вхождения.

### 4.4 Выгрузка

Выгружается весь отфильтрованный срез в табличном формате, одна строка на урок, выбранные и разрешённые колонки. Группа остаётся одной строкой; общие денежные суммы не выдаются за цену одного места. Выгрузка содержит период и часовой пояс, не содержит содержимого записей, чатов, закрытых заметок или временных ссылок на файлы.

Ограничение — 10 000 строк; при превышении предлагается сузить фильтры. В журнале фиксируются сотрудник, параметры, состав колонок и количество строк. Выгрузка не расширяет права просмотра.

### 4.5 Состояния интерфейса

| Ситуация | Поведение |
|---|---|
| Нет уроков за период | Пустое состояние с выбранным периодом и сбросом фильтров |
| Поиск короче 3 символов | Подсказка о минимальной длине |
| Источник ещё обрабатывает результат | Соответствующая метка; итог не объявляется успешно исполненным |
| Ошибка загрузки | Сообщение и повтор; пустой список не подменяет ошибку |
| Урок изменился другим сотрудником | При действии запрашивается обновление и показывается актуальное состояние |

## 5. Правила и ограничения

1. Статус урока, исход ученика, разбор и финансовая обработка — отдельные признаки.
2. Неявка ученика в состоявшейся группе не меняет статус всего урока на «Неявка».
3. Удаление записи не удаляет урок, анонимизация участника не удаляет факт занятия.
4. Открытие списка не предоставляет доступ в комнату, переписку или запись.
5. Список не позволяет произвольно редактировать статус и проведённые денежные операции.

## 7. Требования

| № | Требование | Трассировка |
|---|---|---|
| SL-1 | Должен быть реализован список уроков с поиском, фильтрами, сортировкой и постраничной навигацией | МВП 18.5, 18.12 |
| SL-2 | Один групповой урок должен соответствовать одной строке с раскрытием исходов мест | МВП 5.7, 7.21 |
| SL-3 | Статус урока должен показываться отдельно от разборов, переносов и финансовой обработки | МВП 7.1, 18.5 |
| SL-4 | Должны быть реализованы переходы к карточке, броням и разрешённым действиям | МВП 6.17, 18.5 |
| SL-5 | Должна быть реализована выгрузка до 10 000 строк с проверкой прав и журналированием | МВП 18.10, 18.13 |
| SL-6 | Период, фильтры и сортировка должны сохраняться в адресе, даты — показываться с часовым поясом | МВП 2.20, 18.12 |

## 8. Критерии приёмки

1. Урок с шестью присутствовавшими учениками и одной неявкой показан одной завершённой строкой; фильтр по неявкам его находит.
2. Отклонённая индивидуальная бронь без урока отсутствует в списке, но доступна в бронях.
3. Поиск по идентификатору открывает урок, поиск по старому email удалённого участника его не раскрывает.
4. Переданная коллеге ссылка сохраняет период и фильтры с учётом его прав.
5. Менеджер не видит выгрузку; сотрудник без права записи не получает её метаданные в списке.
6. Отмена, возврат по которой ещё обрабатывается, не отображается как завершённый возврат.
7. Выгрузка группы не умножает урок на число учеников и не содержит ссылок на видео.
