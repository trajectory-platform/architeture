# assets

Изображения, скриншоты макетов и схемы, используемые в документации.

Правила:

1. Имя файла отражает раздел и экран: `teacher-students-table.png`, `student-home.png`, `room-board.png`.
2. Скриншоты макетов берутся из проектных прототипов; источник указывается в документе, который на них ссылается.
3. Схемы в текстовом виде (PlantUML, Mermaid) хранятся рядом с исходником, а не только как изображение.
4. Файлы, не используемые ни в одном документе, удаляются.
