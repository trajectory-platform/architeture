# Общие модули клиентской части

> Статус: заготовка. Содержимое детализируется в следующей итерации.

## Назначение

Раздел описывает модули, одинаково работающие в кабинете преподавателя и кабинете ученика. Различия между ролями фиксируются внутри документа модуля, а не дублированием документа.

## Состав модулей

| Модуль | Содержание |
|---|---|
| Вход и регистрация | Регистрация, подтверждение email, вход по паролю и через внешних провайдеров, восстановление пароля |
| Профиль и настройки | Личные данные, аватар, часовой пояс, тема оформления, настройки уведомлений, документы, выход |
| Переключение роли | Поведение аккаунта, совмещающего роли ученика и преподавателя |
| Комната урока | Доска, медиа, чат комнаты, участники, заметки, таймер, запись, завершение занятия |
| Проверка оборудования | Экран перед входом в комнату: микрофон, камера, соединение |
| Чаты | Список чатов, переписка, вложения, статусы прочтения, поиск |
| Уведомления | Лента, счётчик непрочитанного, всплывающие уведомления, настройки |
| Поддержка | Создание обращения, переписка, статусы |
| Файлы и вложения | Загрузка, ограничения, превью, скачивание |
| Ошибки и пустые состояния | Единые сценарии отсутствия данных, потери связи, отказа доступа |

## Планируемые документы

| Документ | Содержание |
|---|---|
| `Вход и регистрация.md` | Экраны, поля, валидации, сценарии ошибок, внешние провайдеры |
| `Профиль и настройки.md` | Состав по ролям, поля, правила изменения |
| `Комната урока.md` | Экран, инструменты доски, медиапанель, боковая панель, права по ролям, поведение при обрыве связи |
| `Чаты.md` | Типы чатов, экраны, действия, ограничения |
| `Уведомления.md` | Типы событий, отображение, настройки пользователя |
| `Поддержка.md` | Создание обращения, категории, переписка, статусы |
