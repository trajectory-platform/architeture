# Кабинет ученика

> Статус: заготовка. Содержимое детализируется в следующей итерации.

## Назначение

Учебное место ученика: ближайшее занятие, домашние задания, материалы, прогресс, переписка с преподавателем и оплата.

## Характер интерфейса

Упрощённый интерфейс: небольшое число разделов, минимум вложенности, крупные акценты, одно основное действие на экран. Списки простые, без фильтров и сортировок сверх необходимого. Полная адаптивность — мобильный сценарий равноценен десктопному.

**Геймификация присутствует только здесь**: процент прогресса, освоение тем, серия занятий, достижения, цель недели. Она носит мотивирующий характер и не заменяет фактические показатели обучения.

## Разделы

| Раздел | Содержание |
|---|---|
| Главная | Ближайшее занятие с обратным отсчётом и входом в комнату, задания к выполнению, прогресс, последние материалы, сообщение преподавателя |
| Расписание | Упрощённый календарь на неделю и месяц, статусы занятий, запись в свободный слот, перенос и отмена по правилам |
| Домашние задания | Список с фильтром по статусу, карточка задания, отправка работы, комментарий и оценка преподавателя |
| Материалы | Материалы курсов и уроков, записи занятий, конспекты и файлы |
| Прогресс | Освоение тем, результаты тестов, история занятий, достижения, серии, цель недели |
| Чат | Переписка с преподавателем и группой, вложения, чат поддержки |
| Поиск преподавателя | Каталог преподавателей и курсов, фильтры, карточка преподавателя, бронирование пробного или обычного занятия |
| Оплата | Баланс, покупка пакета или абонемента, история списаний, остаток пакета, срок доступа |
| Профиль и настройки | Личные данные, представитель, часовой пояс, уведомления, тема оформления, документы, поддержка, выход |

| Документ | Содержание |

| `Каталог преподавателей.md` | Фильтры, карточка, бронирование, пробное занятие |
