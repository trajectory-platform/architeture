# Клиентская часть

Клиентская часть — веб-приложение для пользователей платформы. Делится на два кабинета с принципиально разными интерфейсами и общий набор модулей.

| Раздел | Содержание |
|---|---|
| [Общее](Общее/README.md) | Модули, одинаковые для обеих ролей: вход, профиль, комната урока, чаты, уведомления, поддержка |
| [Преподаватель](Преподаватель/README.md) | Кабинет преподавателя: расписание, ученики, задания, тесты, материалы, оплата, отчёты |
| [Ученик](Ученик/README.md) | Кабинет ученика: главная, расписание, задания, материалы, прогресс, каталог, оплата |

## Принципиальное различие кабинетов

| Аспект | Кабинет преподавателя | Кабинет ученика |
|---|---|---|
| Характер | Рабочий инструмент, близкий к CRM | Упрощённый интерфейс обучения |
| Плотность информации | Высокая: таблицы, много колонок, компактные строки | Низкая: карточки, крупные акценты, одно действие на экран |
| Навигация | Разделы, вкладки, фильтры, боковые панели с деталями | Небольшое число разделов, минимум вложенности |
| Работа со списками | Сортировка, фильтры, массовые действия, выгрузки | Простые списки со статусами |
| Геймификация | Отсутствует | Присутствует: прогресс, серии, достижения, цели недели |
| Приоритет устройства | Десктоп, мобильная версия для ключевых сценариев | Полная адаптивность, мобильный сценарий равноценен |

Комната урока — общий модуль: единый экран для обеих ролей с разным набором доступных действий.

## Технологические решения

- React, TypeScript, SteroidsJS как основа приложения (маршрутизация, формы, слой данных).
- Единая дизайн-система: токены и компоненты общие, различается композиция и плотность.
- Клиент API генерируется из спецификации, публикуемой API-шлюзом.
- Комната урока — изолированный модуль с собственным жизненным циклом соединений.
- Поддержка светлой и тёмной темы.
