# Кабинет преподавателя

> Статус: заготовка. Содержимое детализируется в следующей итерации.

## Назначение

Рабочее место преподавателя: расписание, ученики, домашние задания, тесты, материалы, отчёты и деньги в одном интерфейсе.

## Характер интерфейса

Плотный рабочий интерфейс, близкий к CRM: таблицы с большим числом колонок, фильтры и сортировки, боковые панели с деталями сущности, массовые действия, выгрузки. Приоритетное устройство — десктоп; ключевые сценарии (вход в урок, чат, проверка задания) работают на мобильном.

Элементы геймификации в кабинете преподавателя не используются.

## Разделы

| Раздел | Содержание |
|---|---|
| Главная | Сводка дня: ближайшее занятие с входом в комнату, расписание на сегодня, очередь проверки, новые сообщения, начисления за период |
| Расписание | Календарь на день, неделю и месяц; создание, перенос, отмена занятий; настройка доступности и исключений; заметки к занятию |
| Ученики | Таблица учеников с прогрессом, заданиями и статусом доступа; вкладки «Мои» и «Закреплённые»; боковая панель ученика |
| Домашние задания | Очередь проверки, создание и выдача заданий, проверка работ, шаблоны |
| Тесты | Создание, назначение, результаты, ручная проверка развёрнутых ответов |
| Материалы | Библиотека материалов курсов, записи проведённых занятий, снимки досок |
| Сообщения | Чаты с учениками и группами, поиск, вложения, переход в комнату, чат поддержки |
| Оплата | Баланс к выплате, начисления, история операций, реквизиты, запрос выплаты, автовывод, справка |
| Отчёты | Отчёты по ученикам и нагрузке, журнал прогресса, посещаемость |
| Профиль и настройки | Личные данные, предметы, цена и длительность занятия, описание, часовой пояс, уведомления, документы, переключение роли |
